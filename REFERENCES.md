## Source precedence

The skill should prefer:

1. the most directly relevant primary source for the question;
2. current official standards or source documentation when the question is time-sensitive;
3. independent corroboration;
4. older books for durable methods rather than current facts.

A book in the corpus should never be treated as proof of a current fact merely because it is authoritative.
