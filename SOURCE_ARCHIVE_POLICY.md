# Source Archive Policy

The original reference archive was supplied separately for analysis.

This GitHub-ready package intentionally does **not** include the 49 PDFs. The repository contains:

- source inventory;
- source-to-module mapping;
- operational summaries;
- schemas;
- routing logic.

Keep licensed or otherwise lawfully obtained source PDFs in a private/local knowledge directory when needed. Do not redistribute copyrighted books simply because they were used to build the skill.

The runtime can still cite the source IDs (`S01`–`S49`) and source titles.

## External inspirations (v4.0.0)

Starting in v4.0.0, some knowledge modules and the tool inventory also draw on operational patterns from third-party open-source "agent skill" repositories (multi-engine skill packaging, cybersecurity/OSINT domain lists, data-journalism production pipelines, narrative-craft techniques). None of that third-party code or prose is redistributed here either — see `CREDITS.md` for the full list, what was (and was not) adapted, and links to each original project.
