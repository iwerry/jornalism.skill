# Credits and External Inspirations (v4.0.0)

`investigativejournalism.skill` remains built on the 49-source PDF library documented in `sources/manifest.json`, `REFERENCES.md` and `ANALYSIS_REPORT.md`. Version 4.0.0 additionally reviewed a set of third-party open-source "AI agent skill" projects, at the request and pointer of a repository contributor, to see which operational *patterns* (not text or code) were worth adapting into this journalism-specific skill.

**None of the projects below had their text, code, prompts or skill files copied into this repository.** Where a pattern was adopted, it was rewritten from scratch for this skill's journalism domain, its evidence model, and its ethics gates, and the corresponding knowledge module says so explicitly. Where a project's focus did not fit investigative journalism, it is listed as reviewed and set aside, per the request to keep only what makes sense ("o que não fizer sentido, deixa pra lá").

## How to update this file
When a new external skill or tool is folded into a future version:
1. State what the source project actually is, verified where possible rather than assumed from its name or a search snippet.
2. State explicitly what was adapted (a *pattern*, never verbatim text/code) and into which knowledge module.
3. If the project's content conflicts with this skill's ethics gates (Golden Rules, `knowledge/ETHICS_AND_SAFETY.md`, the offensive-security exclusion above), the gate wins and the conflicting part is left out — note that exclusion here rather than silently dropping it.
